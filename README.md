# homebrew-tap

Homebrew tap for [bufferings](https://github.com/bufferings).

## Usage

```sh
brew install --cask bufferings/tap/shiibar-cc
brew install bufferings/tap/jai-smell
```

| Name | Type | Description |
| --- | --- | --- |
| [shiibar-cc](https://github.com/bufferings/shiibar-cc) | Cask | Menu bar app that tracks Claude Code status and jumps to its iTerm2 tab |
| [jai-smell](https://github.com/bufferings/jai-smell) | Formula | Flags unnatural Japanese expressions in text written by Claude Code |

See each repository for what it is and how to set it up.
